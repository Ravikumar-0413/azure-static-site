Static Website
Deployment Journey

A simple HTML, CSS and JavaScript website deployed automatically from Azure Repos through a Classic Build Pipeline and Release Pipeline into Azure App Service.

Explore the Process ↓

END-TO-END FLOW

From source code to production

Every stage below represents a real part of the deployment workflow.

01
SOURCE

Azure Repos

Store index.html, CSS, JavaScript and images in the Git repository.

↓
02
BUILD

Classic Build Pipeline

Use the Classic Editor to copy website files into the artifact staging directory.

↓
03
ARTIFACT

Publish Build Artifact

Publish the website as a drop artifact for the release pipeline.

↓
04
RELEASE

Classic Release Pipeline

Download the build artifact and pass it to the Azure App Service deployment task.

↓
05
PRODUCTION

Azure App Service

The HTML, CSS and JavaScript files are hosted and served through an Azure web app.
